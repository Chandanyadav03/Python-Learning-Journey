# Chapter 2 - Variables and Data Types

## Topics Learned

### 1. Variables
Variables are used to store data in Python.

Example:
```python
name = "Vipul"
age = 20
```

### 2. Data Types
Python supports different data types:

- int
- float
- str
- bool
- NoneType

Example:
```python
a = 10
b = 10.5
c = "Hello"
d = True
e = None
```

### 3. Rules for Variable Names

- Variable names can contain alphabets, digits, and underscores.
- Variable names must start with a letter or underscore.
- Variable names cannot start with a digit.
- Spaces are not allowed in variable names.

Valid Examples:
```python
name
age1
_student
```

### 4. Operators

Python Operators:

- Arithmetic Operators (+, -, *, /, %)
- Comparison Operators (==, !=, >, <)
- Logical Operators (and, or, not)
- Assignment Operators (=, +=, -=)

Example:
```python
a = 10
b = 5
print(a + b)
```

### 5. Type Function

The `type()` function is used to check the data type of a variable.

Example:
```python
a = 10
print(type(a))
```

Output:
```
<class 'int'>
```

### 6. Input Function

The `input()` function is used to take input from the user.

Example:
```python
name = input("Enter your name: ")
print(name)
```
