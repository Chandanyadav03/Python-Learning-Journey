# Chapter 4 - Lists and Tuples

## Topics Covered

### 1. Lists

A list is an ordered and mutable collection of items.

Example:

```python
fruits = ["Apple", "Banana", "Mango"]
```

### 2. List Methods

Common list methods:

```python
append()
insert()
remove()
pop()
sort()
reverse()
count()
```

### 3. Tuples

A tuple is an ordered and immutable collection of items.

Example:

```python
marks = (90, 85, 78, 92)
```

### 4. Tuple Methods

```python
count()
index()
```
